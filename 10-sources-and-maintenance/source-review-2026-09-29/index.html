Source corrections, 29 September 2026

These checks apply only to the claims listed below. They do not renew the inherited verification dates for entire articles, establish product compatibility, or replace licensed standards and equipment tests. All sources below were accessed on 29 September 2026.

On this page
  • Corrected document identities
  • Current catalogue snapshots
  • Moved and unavailable documentation

Corrected document identities#

Claim checked Primary evidence Result and limit
AV1 RTP payload specification AOMedia v1.0.0 AOMedia identifies this as its final deliverable dated 15 December 2024. The former RFC 9364 attribution was incorrect. Codec performance and product interoperability were not tested.
IEC access control Web services edition IEC 60839-11-33:2021 catalogue Corrected the edition year from 2016 to 2021 and the title to access control configuration. Only the public catalogue scope was reviewed, not the licensed normative text.
OPC UA discovery section Part 4, section 5.5 Discovery services are in section 5.5 of the current reference. The former section 5.4 link resolved to locale negotiation.
NIST SP 800-82 revision work Rev. 4 pre draft record The linked item is a pre draft call for comments, not a replacement final guide.
SOAP 1.2 reference W3C Part 1, second edition Replaced the general SOAP index with the dated messaging framework recommendation.

Current catalogue snapshots#

Claim checked Primary evidence Result and limit
Matter specification availability CSA downloads The catalogue lists Matter 1.6.1. This confirms availability, not new patch features or device support. The separate 1.6 announcement remains the evidence for that release's features.
OpenTelemetry specification version Specification index and OTLP index The indexes identify specification 1.61.0 and OTLP 1.11.0 respectively. Implementation and semantic convention versions remain independent.

Moved and unavailable documentation#

The BACnet Secure Connect, BACnet addenda, OPC UA profile catalogue, IEC 61850 cybersecurity, NIST face evaluation and Modbus document links were updated using their publishers' current navigation. A working catalogue does not demonstrate support for every claim in a document behind it.

The former Hanwha STEP and LenelS2 PDF links returned 404. Those historical references are now described as unavailable, with current official portals supplied for follow up. No replacement product evidence was inferred from a portal homepage.

The former KNX checklist PDF redirected to a generic homepage. The article now links to KNX installation security guidance and explicitly asks readers to obtain the current checklist before treating it as acceptance evidence.

Review limits#

A working link does not establish that its source supports a claim. Some vendor documents require an account, and many standards expose only catalogue metadata. The checks above cover the stated claims; other technical review dates remain unchanged. Obtain the applicable product documents and standards before using this reference for an installation decision.
