Physical access control systems

Access control links identities and credentials to decisions made by controllers. These pages cover the readers, doors, permissions and operating conditions involved.

On this page
  • Overview
  • Pages
  • Decision chain
  • Source baseline

Overview#

Physical access control spans identity governance, credential issuance, local controller decisions, door hardware, life safety behaviour, and audit. Treat each as a separate authority.

Decision chain#

text
person -> identity/account -> credential -> reader transaction
       -> controller/PACS policy -> lock/turnstile/lift request
       -> sensed door/passage state -> immutable audit/event lifecycle

An access granted decision, unlock output, door contact change, and confirmed passage are different facts. Preserve uncertainty.

Source baseline#

IEC 60839-11-1:2013 establishes public scope for electronic access control system/component functionality, performance, logging, identification, and information control. IEC 60839-11-5:2020 specifies OSDP between access control units and peripherals. ONVIF Profiles A, C, and D address access configuration, basic door/events, and peripherals respectively; verify exact product conformance and conditional features.
