# Perimeter and detection systems

Effective perimeter security layers deterrence, delay, detection, assessment, response, and recovery. No sensor independently proves intent or identity; fuse observations while preserving each source and uncertainty.

[IEC 62676-6:2026](https://webstore.iec.ch/en/publication/59704) covers testing/grading real-time intelligent video analysis, including intrusion and complex scenarios under operating stress. Powered gates/barriers are machinery: apply the local product standard and risk process; [ISO 12100:2010](https://www.iso.org/standard/51528.html) provides general machinery risk-assessment principles and is expected to be replaced, so check current status.
