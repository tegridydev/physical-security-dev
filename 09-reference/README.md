## Reading rules

1. Treat port numbers and discovery responses as hints, never identity or authorization.
2. Resolve a family name to an exact edition, profile, role, transport, secure mode, and product version.
3. Follow links to the canonical deep page before implementation.
4. Keep observation and actuation decisions separate.
5. Record uncertainty, evidence, and validation scope using the [verification policy](../10-sources-and-maintenance/verification-policy.md).
